    model "haiku"  for finding files, grep, listing, reading and summarising one file, git commands

BEFORE reading code or delegating the question, prepare fresh repository copies:
1. Remove only the old collection files .ekka/answer.md and .ekka/ask-record.json, if present. Refuse links
   in .ekka and its paths; do not follow them. Prior answer files under .ekka/answers may remain.
2. Read and retain the ENTIRE .ekka/desk-map.json before changing any repository. It must contain a
   non-empty repositories list. If missing, invalid or empty, fail without answering.
3. Validate EVERY entry before deleting any folder:
   - The address is https://github.com/<owner>/<repo>, optionally ending .git. No user name, password,
     port, query, fragment, whitespace or extra path segments. Owner and repo use letters, digits, dots,
     underscores or hyphens; neither may be empty, dot or parent-directory.
   - The folder is an immediate child of /sandbox/ekka-workspace, named exactly after the repo without
     its .git suffix. Never the workspace itself or .ekka, never outside it. Reject duplicate folders.
   - No path component is a symbolic link. A present folder must contain a real .git directory inside it,
     not a link or a .git file naming another checkout. Refuse any other existing folder.
   On any invalid entry, change no repository and fail. Do not guess another folder or address.
4. For each validated entry, list/count its existing regular files without following links for the
   discard record. Do NOT run Git in the old clone: its local config, filters and hooks are untrusted.
   Remove the OLD COPY, including .git and ignored/untracked files, using rm -rf -- <validated-folder>.
   Never delete any other folder, the workspace root, the agent's home, or EKKA's staged inputs.
5. Clone each retained address into its now-absent folder, using ordinary Git and fixed clean settings:
   env -u GIT_CONFIG_PARAMETERS -u GIT_CONFIG_COUNT GIT_CONFIG_NOSYSTEM=1 GIT_CONFIG_GLOBAL=/dev/null git -c core.hooksPath=/dev/null -c core.fsmonitor=false -c protocol.allow=never -c protocol.https.allow=always -c http.followRedirects=false -c credential.helper= clone --template= --no-local --no-recurse-submodules -- <address> <folder>

   replace only credential.helper= with the existing placeholder recipe:
   credential.helper='!f() { echo username=x-access-token; echo "password=$GITHUB_TOKEN"; }; f'
   Never print, write or log GITHUB_TOKEN, headers or credential-helper output. Never push.
6. Verify each clone exists, its actual origin is the retained address and its branch/commit can be read.
   Update desk-map.json with those measured commits. If any removal, clone or verification fails, fail
   without answering; never read the previous copy as a fallback. Keep all repository scripts, hooks,
   dependency installation and submodule initialization disabled.
