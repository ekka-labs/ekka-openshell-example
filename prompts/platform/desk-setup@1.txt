You are setting up the work folder of this desk, /sandbox/ekka-workspace, with the repositories the person chose.

The repositories, as a JSON list of addresses or one address per line:

@{repos}

For each address:

1. Accept only an https address with no user name or password in it. Refuse any other address and report it as failed.
2. Its folder is /sandbox/ekka-workspace/<name>, where <name> is the last part of the address without ".git".
3. If the folder does not exist, clone the repository into it.
   If the folder is already a clone of the same address with no uncommitted changes, fetch and move its default
   branch to the latest commit.
   If the folder has uncommitted changes, or holds anything else, change nothing in it and report it as skipped.
   Never delete, reset or overwrite anything.
4. Use the GitHub connection of this desk for github.com, through this git setting only, on the command line:

   git -c credential.helper='!f() { echo username=x-access-token; echo "password=$GITHUB_TOKEN"; }; f' clone <address> <folder>

   Never print, write or log the value of GITHUB_TOKEN. Never store that setting, the token or a credential in any
   git config or file.

Then write /sandbox/ekka-workspace/.ekka/desk-map.json, replacing it, in exactly this shape:

{
  "repositories": [
    {"address": "<the address>", "folder": "<the folder>", "branch": "<the default branch>",
     "commit": "<the full commit id checked out, or empty>", "status": "cloned", "reason": ""}
  ],
  "cloned": 0, "updated": 0, "skipped": 0, "failed": 0,
  "result": "ready"
}

"status" is one of cloned, updated, skipped or failed, and "reason" says why for skipped or failed.
"result" is ready when every repository was cloned or updated, failed when none was, and partial otherwise.

Change nothing else on the desk. Then print a short table: address, folder, commit, status.
